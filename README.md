# Atobs Portfolio Website

A responsive dark portfolio website made with beginner-friendly HTML, CSS and JavaScript.

## Files
- `index.html` — the page structure and content
- `style.css` — dark theme, responsive layout, animations and project mockups
- `script.js` — mobile menu, scroll reveals, project filters and contact form demo

## Run it in VS Code
1. Extract `atobs-portfolio.zip` to a folder on your computer.
2. Open VS Code.
3. Choose **File → Open Folder** and select the `atobs-portfolio` folder.
4. Open `index.html`.
5. If you have the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**.
6. If you do not have Live Server, you can open `index.html` directly in your browser.

## Personalize before publishing
1. Search `index.html` for `Atoba Sulaiman` and edit the name if you want.
2. Replace `hello@atobs.dev` with your real email in both `index.html` and `script.js`.
3. Replace the GitHub, LinkedIn and X links with your own profile URLs.
4. Edit the project descriptions so they accurately describe your work. The project thumbnails on this starter site are CSS illustrations, not screenshots of live websites.
5. Update the skill indicators to reflect your real experience.
6. For a contact form that sends messages without opening the visitor's email app, connect a form service or your own backend. This demo does not store or send messages by itself.

## Notes
- The Google Fonts import needs an internet connection. The site still has fallback fonts if the font service is unavailable.
- The layout adapts to mobile, tablet and desktop screen sizes.
- Animations respect the visitor's reduced-motion accessibility preference.
